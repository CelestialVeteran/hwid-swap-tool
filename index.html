Capabilities

Everything a full hardware reset needs

Six independent modules that can be run individually or chained together into a single one-click spoof profile.

💽

Disk Serial Swap

Rewrites volume and physical drive serial numbers exposed through SMART and WMI, including NVMe and SATA controllers.

🧬

SMBIOS & Motherboard IDs

Regenerates System UUID, baseboard serial, chassis asset tag and BIOS version strings reported by the firmware tables.

🌐

MAC Address Rotation

Assigns a consistent randomized MAC per adapter, with vendor-prefix validation so the new address stays plausible.

🎮

GPU UUID Swap

Replaces the graphics adapter UUID and device instance path used by Vulkan, DirectX and driver-level enumeration.

🧹

Registry Trace Cleaner

Scans and removes stale hardware fingerprints from HKLM, MountedDevices and per-user device history keys.

🔒

Persistence & Restore

Applies the spoof at boot so it survives updates and restarts, with a full rollback snapshot stored before any change.
